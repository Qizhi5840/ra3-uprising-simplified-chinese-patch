## 一、准备工作：查找游戏安装目录

在安装补丁前，你需要先找到《红色警戒3：起义时刻》在电脑中的安装路径：

*   **Steam 玩家**：
    在 Steam 游戏库中，右键点击《Command & Conquer: Red Alert 3 - Uprising》-> 选择 **【管理】** -> **【浏览本地文件】**。
*   **学习版玩家**：
    直接打开你安装游戏的根目录（包含 `RA3EP1.exe` 的文件夹）。

请**确保游戏内语言设置为英文**（本补丁本质上是替换了英文语言包的内容）
> 游戏语言不是英文？Steam版可以直接在属性-通用页面修改，学习版玩家需要创建 `ra3ep1.exe`的快捷方式，右键点击属性，在目标选项中，文件路径的后面加一个“ -ui”尾缀（注意前面有一个空格），双击会打开控制台Launcher，将语言切换为**English**并运行即可修改。

## 二、方案一：覆盖式安装（推荐 99% 的玩家）

本方案将汉化文本与优化字体伪装打包进默认英文包中。**你不需要设置任何启动参数**，启动游戏即可自动显示简体中文。

### 安装步骤：

1. 从本仓库的 [Release 页面](../../releases) 下载最新的 `RA3_Uprising_ZH_Hans_Patch.zip`。
2. 解压压缩包，打开方案一文件夹，解压 `English.big` 。
3. 打开你的游戏安装目录，进入 **`Data` 文件夹**。
4. 最好备份原先的`English.big`。
5. 将解压出的 `English.big` 粘贴到 `Data` 文件夹中，**选择“覆盖原文件”**。
6. 正常启动游戏，补丁安装完成！

> 针对Steam玩家：
> 如果你在平台中点击了 **“验证游戏完整性”** 或 **“修复游戏”**，平台会自动下载官方原版英文包把你修改后的文件覆盖掉。届时只需重新将本补丁文件复制进去替换即可。

## 三、方案二：独立语言包安装

如果你用的是学习版，不想覆盖原版的英文语言包，希望保留多语言切换的能力，可以使用独立语言包挂载方案。

> Steam 玩家：Steam 会在每次启动游戏时，自动将语言强制同步为“属性-通用”页面中设置的语言。因此**本方案对 Steam 版无效**，请使用[方案一](#二方案一覆盖式安装推荐-99-的玩家)覆盖式安装。

### 安装步骤：

1. 从 Release 页面下载独立语言包，解压后将得到以下两个文件。
2. 按照表格说明，将以下文件放到对应位置：
   | 文件名称 | 放置路径 |
   | --- | --- |
   | `ChineseS.big` | 游戏目录下的 **`Data` 文件夹** 内 |
   | `RA3EP1_chinese_s_1.0.SkuDef` | 游戏根目录内 |
   | `RA3EP1_chinese_s_1.1.SkuDef` | 游戏根目录内 |
   | `chinese_s.csf` | 游戏目录下的 **`Launcher` 文件夹** 内 |
3. 创建 `ra3ep1.exe`的快捷方式，右键选择【属性】。
4. 在【目标】一栏的最后面，**加上一个空格，再输入 `-ui`**。
   > 正确示例：`"D:\Games\RA3 Uprising\ra3ep1.exe" -ui`
5. 点击确定。双击该快捷方式启动游戏，在弹出的控制台（Launcher），将语言切换为 **简体中文**，点击启动。
