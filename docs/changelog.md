# 更新日志 / Changelog

本文档记录本翻译补丁各版本的文本修正与功能变更。

---
v1.0.0

## 更新内容

- **文本全面精翻**：基于 AI 初稿 + 人工逐句复核，对战役剧情、指挥官挑战、单位台词、UI 界面等全部有效文本进行了深度重构与润色。
- **字体优化**：替换原版字体为 HarmonyOS Sans，大幅提升中文显示清晰度与排版美观度。
- **时间轴调整**：针对中文语速重新校准了过场字幕的时间戳，合并了不合理断句，确保字幕与语音同步流畅。

## 安装方法

> 推荐 99% 的玩家使用覆盖式安装，无需任何启动参数，即装即玩。

1. 下载本 Release 中的 `RA3_Uprising_ZH_Hans_Patch_v1.0.0.zip` 并解压。
2. 打开游戏安装目录下的 `Data` 文件夹，将原版的 `English.big` 备份后，用补丁包中的 `English.big` 覆盖替换。
3. **确保游戏内语言设置为英文**（本补丁本质上是替换了英文语言包的内容），启动游戏即可生效。

> 详细安装说明及多语言切换方案，请查阅压缩包内安装指南。
