# 红色警戒3 时间戳语法与修改指南

> 本文档专门解析 `.csf` 文本文件中出现的时间戳语法，以及在汉化/修改过程中重算与合并时间戳的规则。

---

在过场动画的字幕文本中，我们经常会看到类似下面这样带有大量中括号的字符串：

```ini
[SUBTITLE:FFS01_01]
[10.8:3.1]啊，你终于来了。[15.1:3.7]战斗控制中心终于上线了，一切已准备就绪。[19.2:3]我们已经弄到了三大势力的基地车，[22.4:1.8]现在全部交由你调遣。[24.5:3.6]战后的局势因边境争端而陷入僵局，[28:2.2]根本没人会注意到你的行动。[30.7:3.3]我们会在一旁待命，收集战斗残骸中的技术样本，[34.2:0.9]用不了多久，[35.4:3.9]他们的全部军事装备就都会在我们手中，任我们处置。[39.9:2.1]或者，随你处置。[42.4:0.9]祝你好运。[44.4:3.3]我们会密切关注你的进展。
```

这些形如 `[10.8:3.1]` 的标记就是**时间戳**, 代表视频播放至 10.8 秒时弹出字幕，并持续显示 3.1 秒。我们可以通过调整这些时间戳，来优化中文字幕的断句与显示节奏。

再以其中这段字幕为例：
`[19.2:3]我们已经弄到了三大势力的基地车，[22.4:1.8]现在全部交由你调遣。[24.5:3.6]……`
在汉化过程中，由于中文翻译通常比英文更精炼，原有的 `[22.4:1.8]` 时间戳显然不合适，需要将其删除。

---

## 一、时间戳的语法结构

时间戳语法遵循 **`[开始时间:持续时长]`** 的标准格式（单位均秒，支持一位小数）。其在实际文本中有 **标准形式** 与 **特例** 两种形态：

| 形态 | 语法规则 | 适用场景 | 参考 |
| :--- | :--- | :--- | :--- |
| **标准时间戳** | `[开始秒数:持续时长]` | 视频过场字幕 | [SUBTITLE:FFS01_01] |
| **特例** | `[开始秒数]` *（省略持续时长）* | EVA语音 | [DIALOGEVENT:MS04_SOVIETINTEL36] |

---

## 二、特例形态：省略持续时间的标准时间戳

单参数时间戳并非另一种独立语法，而是**标准时间戳省略了持续时长后的特例（简写形式）**。

```ini
[DIALOGEVENT:MS04_SOVIETINTEL35]
就是这里了，指挥官。[1.4]我们一路追踪未来科技来到这座岛屿……
```
这里，`[1.4]` 表示在该语音事件触发 **1.4 秒后** 切换显示第二句文字，前面的时间戳为 `[0.0]`，这是可以省略的。
这种特例时间戳主要适用于EVA播报语音和小兵放话语音。

---

## 三、时间戳的合并与重算规则

在汉化过程中，中文翻译往往比英文更精炼。为了避免中文字幕频繁断句，我们需要**删除中间冗余的时间戳**，并重新计算当前字幕的持续时长。

若要删除中间的多余时间戳并将多句字幕合并，**当前时间戳的新持续时长** 计算公式为：

$$\text{新持续时长} = \text{下一句时间戳起点} - \text{当前时间戳起点} - 0.1$$

>这里我扣除 0.1 秒是为了防止首尾时间紧衔接导致字幕渲染重叠。若实际测试仍有重叠，可适当加大扣除值，但务必保留一位小数。

举个例子：
```ini
[SUBTITLE:FFS01_01]
……[19.2:3]我们已经弄到了三大势力的基地车，[22.4:1.8]现在全部交由你调遣。[24.5:3.6]战后的局势……
```
我们要删去中途的 `[22.4:1.8]` 时间戳，将前两句话合并为一句。
我们注意到前面的字幕起点：$19.2$ 秒，下一句字幕起点：$24.5$ 秒，如果把中间的时间戳删掉，那么我们必须延长前面的字幕持续时长。
套用公式计算新持续时长：
   $$\text{新持续时长} = 24.5 - 19.2 - 0.1 = 5.2\text{ 秒}$$
我们验算一下：
   $$\text{当前字幕结束时刻} = 19.2 + 5.2 = 24.4\text{ 秒}$$
结束时刻 $24.4$ 秒小与下一句起点 $24.5$ 秒，这样应该能避免字幕重叠。

**这样，我们就得到了修改后的最终文本：**
```ini
……[19.2:5.2]我们已经弄到了三大势力的基地车，现在全部交由你调遣。[24.5:3.6]战后的局势……
```

---

## 四、注意事项

1. 方括号 `[` `]` 和冒号 `:` 必须为英文半角字符。
2. 结束时刻（$\text{起点} + \text{时长}$）不要大于下一句的起点时刻，否则会导致字幕堆叠。

> 本文档总结的时间戳规律，是我在汉化工作推进到中后期才“后知后觉”摸索出来的（其实早就应该发现了，不就是找规律嘛）。
> 因此，语言包中早期翻译的部分过场字幕，可能仍存在未来得及优化的时间戳或轻微重叠现象。如果您在游玩过程中遇到了**严重的字幕重叠问题**，欢迎带上截图（手机拍屏也可以的）到 [Issues](../../issues) 页面反馈，我会尽快跟进修正！
