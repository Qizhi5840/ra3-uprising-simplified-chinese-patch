## 快速使用指南

推荐 **99% 的玩家** 使用覆盖式安装，无需任何启动参数，即装即玩。

1. 从 [Release](../../releases) 下载最新的 `RA3_Uprising_ZH_Hans_Patch.zip` 并解压。
2. 打开游戏安装目录下的 `Data` 文件夹，将原版的 `English.big` 备份后，用本补丁 `方案一` 文件夹中的 `English.big` 覆盖替换。
3. **确保游戏内语言设置为英文**（本补丁本质上是替换了英文语言包的内容），启动游戏即可，补丁自动生效！
* 游戏语言不是英文？Steam版可以直接在属性-通用页面修改，学习版玩家需要创建 `ra3ep1.exe`的快捷方式，右键点击属性，在目标选项中，文件路径的后面加一个“ -ui”尾缀（注意前面有一个空格），双击会打开控制台Launcher，将语言切换为**English**并运行即可修改。

> 如需保留多语言切换功能（独立语言包安装），请查阅 [完整安装指南](docs/install_guide.md)。  
> 如果你想实现实现粗体/常规体完美区分，可参考 [字体优化与自定义教程](docs/font_tutorial.md) 中的“繁体中文包方案”。

## 项目简介 / Introduction

《命令与征服：红色警戒3 - 起义时刻》（Command & Conquer: Red Alert 3 - Uprising）是 EA 于 2009 年发行的独立资料片。官方中文版存在较多机翻痕迹、术语前后不一致、语句生硬等问题，一定程度上影响了剧情代入感与游戏体验。

本项目旨在：

- **文本重译**：以 AI 生成初稿为基础，结合作者对游戏背景和语境的了解，对玩家能够体验到的**所有有效文本**（包括战役剧情、指挥官挑战、单位台词、UI 界面等）进行逐句调整和语义修正，尽量还原英文原意并保持中文表达的通顺。

- **字体优化**：替换原版生硬的繁体中文字体，采用HarmonyOS Sans，提升中文显示的清晰度与排版美观度。

## 关于翻译润色与 AI 辅助的说明

本项目以 AI 工具生成初稿提升基础效率，由作者（我）全程主导翻译方向、考证《红警3》背景术语并监督语义一致性。由于 AI 无法准确理解游戏语境与角色语气，所有译文最终均由作者进行了逐句人工复核、语义修正与修辞润色，确保既忠实于英文原意，又符合红警世界观与中文阅读习惯。
